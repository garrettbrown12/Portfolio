ORENTH

Orenth is a desktop application designed to help users manage their gaming library and get recommendations based on 
their current "vibe." Built with Python and utilizing SQLite for data persistence, the application features a modern GUI
developed with CustomTkinter.

----FEATURES----
Vibe based recommendations:
  Get a random game suggestion tailored to the mood you choose.
Track Stats:
  Automatically keeps track of how many times you have played each game.
Most Played:
  Use the tracked stats to find out your most played game per vibe.
Easy Management: 
  Add New games to your library via a simple, user-friendly interface.
Fresh Start:
  quickly reset your database when you want a clean slate

-----TECHNOLOGIES USED------
Python
SQLite
CustomTkinter

-----INSTALLATION-----
1. Clone this repository
2. install the required dependencies:
     ```bash
     pip install customtkinter
      ```
3. run the application
   ```bash
   python app_gui.py
   ```
